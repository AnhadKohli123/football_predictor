How to read these numbers
The test set is chronological, not random. The model trains on older matches and is scored on more recent ones. A random split would let it train on 2025 matches and be tested on 2019 ones — it would already know how those teams turned out, and the accuracy would look far better than anything you would ever see on a real fixture.
Log loss judges the probabilities, not just the winner. Accuracy alone flatters this problem, because always predicting a home win is a surprisingly strong baseline. If the model does not beat the class-prior log loss, it has learned nothing useful.
Draws are rarely the top prediction. Home and away wins are called reasonably well; draws almost never rank first, because they seldom carry the strongest signal. Read the draw percentage rather than the headline call when that is what you care about.
Club football is harder than international football. League opponents are far more evenly matched than a World Cup group stage, where genuine mismatches are common — so expect roughly 48–53% here, against a 43% always-home baseline. Treat every output as odds, not as an answer.
